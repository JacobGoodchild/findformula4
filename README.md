# findformula4
Open-ended search for a general, citeable theorem in classical mathematics (graphs, random walks, electrical networks, polynomials). The brief is in CLAUDE.md, which also holds the progress log.

**Status (end of session 1):** no headline result. See MORNING_SUMMARY.md (plain English), results.md (one modest, referee-checked item), IDEAS.md (every idea tried and its fate), NOVELTY.md (literature checks), NOTES.md (dead ends and leads). `python3 verify_all.py` re-runs the main checks.

Layout: `results/graphs_explore` (invariant scans), `results/random_target` (Kemeny / random-target lemma probes), `results/resistance_simplex` and `results/circumsphere` (the effective-resistance simplex: Cayley-Menger, circumsphere, proofs), `results/ust` (random spanning tree probes), `results/critical_gaps`.
